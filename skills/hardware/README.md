# Hardware

Fork-owned hardware, schematic, and PCB engineering skills kept outside the
`mattpocock/skills` synchronization boundary.

- [`kicad-schematic`](kicad-schematic/SKILL.md) — Define opening electrical parameters, design and review KiCad schematics (`.kicad_sch`), verify footprints, BOM/DNP fields, and cross-board pin mappings, and prepare for ERC.
- [`kicad-pcb`](kicad-pcb/SKILL.md) — Configure `.kicad_pro` and `.kicad_dru` design rules, place and route KiCad PCBs (`.kicad_pcb`), apply silkscreen placement, 4-layer power, or 2-layer reduction rules, and resolve layout bottlenecks.
- [`kicad-release`](kicad-release/SKILL.md) — Execute KiCad 10 CLI ERC/DRC and schematic-parity verification, clean dangling tracks/vias in a working copy, enforce zero-error sign-off gates, and export Gerber, drill, BOM, and POS deliverables.
